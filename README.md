# UI Automation Project — Playwright

## Установка

```bash
pip install -r requirements.txt
playwright install
```

## Подготовка

Создайте файл `.env` на основе `.env.example`.

## Запуск тестов

```bash
pytest -v
```

## Что нужно реализовать

- 3 теста для формы заказа
- Скриншоты при падении тестов
- Конфигурацию Playwright
- Pull request для проверки наставником
